# 知序 · 华为 PC 营销工作台（本地资料版）

以本地华为 PC 产品事实和图片为依据，按人群、场景和平台生成营销图文，并附逐项事实引用、配图来源和核验记录。

## 运行

需要 Node.js 22 或更新版本。项目使用 Node.js 内置模块，无需安装 npm 依赖。

1. 将工作人员提供的知识库解压至项目 `华为PC知识库/` 下。也可以设置 `LOCAL_KB_PATH`，指向直接包含 `P1-产品参数库` 的目录。
2. 在环境变量中设置 `LLM_API_KEY2` 为 DeepSeek 官方 API 密钥。默认模型是实测可用的 `deepseek-flash`，可用 `LLM_MODEL` 指定模型名称。
3. 在项目目录执行：

```powershell
.\run-local.ps1
```

或在 Node.js 已加入 PATH 时：

```sh
npm run start:local
```

4. 在浏览器打开 `http://127.0.0.1:8787`。

如果 PowerShell 脚本受本机执行策略限制，可以直接用 `node src/server.mjs` 启动，不必修改系统策略。`run-local.ps1` 也能发现当前电脑中 Codex 随附的 Node.js。

可将 `.env.example` 复制为 `.env` 并在本机填写配置。系统环境变量优先于 `.env`。不要上传 `.env` 或真实密钥；前端只读取“是否已配置”。

| 配置 | 说明 |
| --- | --- |
| `LLM_API_KEY2` | DeepSeek 官方密钥，本地版必须 |
| `LLM_MODEL` | 默认 `deepseek-flash` |
| `LLM_BASE_URL` | 默认 `https://api.deepseek.com`，本版本只接受 DeepSeek 官方域名 |
| `LOCAL_KB_PATH` | 解压知识库根目录；未设置时自动发现项目下的知识库 |
| `PORT` | 默认 8787；也可运行 `./run-local.ps1 -Port 8788` |

本地版无需 ima 凭证，但仍需连接 DeepSeek，不是完全离线软件。资料会发送选中型号的必要事实与平台指南给 DeepSeek，接口密钥只用于官方请求头。

## 使用流程

1. 明确选中具体型号，填写目标人群、使用场景与平台。
2. 查看右侧产品原文与图片索引，确认选对型号。
3. 图片可点击放大，查看文件名、对应型号和官方来源页；任务输入自动保存在当前浏览器，刷新后恢复。
4. 点击生成。系统依次进行场景策略、资料检索、图文编排、原文引用核对、独立模型审核。
5. 有问题时自动修正一次，再次审核；未通过时阻止交付正文。
6. 通过的内容可以复制正文，导出 Markdown、TXT 或包含依据的 JSON。
7. 输入修改要求或更换平台，重新生成并审核，保留原版本。
8. 在运行记录中查看历史结果。历史保存在 `.cache/local/`，只留在本机。

信息不足时先提示补充，不直接消耗生成请求。模型请求失败会展示错误，不使用固定样稿伪造成功。

## 已实现范围

- 用联合参数索引定位 10 个重点型号，仅读取相应产品事实、来源和同目录图片索引。
- 小红书、公众号、门店朋友圈、门店海报四种写作规则。
- 场景策略覆盖开学购机、移动办公、创作、家庭换新与企业采购等任务；事实只来自选中型号。
- 引用原文逐字定位，核对引用ID、图片型号、可用图片数量、平台结构及风险表达。
- 独立模型复核正文、标题、图注和事实清单中的参数及适用条件；这与规则检查互补，不构成事实绝对准确的保证。
- 图片数量不足时明确显示缺口，不重复同一图片或跨型号补图。
- 对已发现的部分尺寸字段错位隔离处理，保留可核对的重量与脚注并提示人工复核。
- 本机 HTTP 服务、图片预览、资料原文、修改、历史、复制和三种导出格式。

## 尚未接入

本版不调用 ima、不实时采集华为商城、不验证优惠或库存，不自动发布到社交平台。官方商城已获工作人员允许作为参考来源，将在后续模块单独标注，不能把本地历史价格当作当前报价。ima 调用版另行开发，共用业务流程。

原始图片在本机展示；Markdown 导出的封面和段后插图位置与页面预览一致，并附索引中的官方图片原始 URL、来源页和文件名，远程图片地址可能变化。

## 代码结构

```text
src/config.mjs        环境配置与知识库定位
src/kb-local.mjs      CSV读取、产品检索、原文与图片来源
src/rules.mjs         场景/平台策略与规则检查
src/llm.mjs           DeepSeek API 适配
src/agent.mjs         生成、审核、有限修正与导出
src/server.mjs        本机 HTTP 接口和静态页面
public/               原生 HTML/CSS/JS 界面
prompts/system.md     完整系统提示词
run-local.ps1         Windows 启动入口
```

未来模型切换主要发生在配置、模型适配层与提示词；切换后需重新验证输出格式与审核效果。不要将中转服务密钥填入 DeepSeek 凭证变量。

## 验证

离线规则与知识库检查：

```sh
npm test
```

运行服务后，执行真实接口验证：

```sh
npm run verify:local
```

真实验证会调用 DeepSeek 并产生相应费用，覆盖两个业务场景、两个发布平台及修改导出；结果写入被 Git 忽略的 `.cache/local-verification/`。平时只需执行离线测试。图片未做视觉识别，资料未实时联网核验，发布前仍需人工检查配置、适用条件及素材授权。
