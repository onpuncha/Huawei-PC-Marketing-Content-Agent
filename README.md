# 知序 · GPT + 华为商城版

这是独立于 DeepSeek 本地版的新版本，默认运行在 http://127.0.0.1:8788 。DeepSeek 版继续运行在8787，原目录和冻结压缩包保持独立。

## 启动

需要 Node.js 22 或更高版本，无需安装 npm 依赖。

1. 在环境变量中保留已有的 `LLM_API_KEY`（4router中转站密钥），或单独设置 `GPT_API_KEY`，后者优先。
2. 需要能找到本地知识库。当前目录结构会自动发现上一层 `华为PC知识库/`；将本版本复制到其他电脑时，设置 `LOCAL_KB_PATH` 指向直接包含 `P1-产品参数库` 的目录。
3. 运行 `./run-gpt.ps1`，或 `node src/server.mjs`。
4. 打开 http://127.0.0.1:8788 。

配置文件 `.env.example` 可复制为 `.env` 在本机填写，真实密钥不得提交。版本只读取GPT专用配置，不会读取DeepSeek的LLM_MODEL等配置。默认模型 `gpt-6.1-sol`，也可设置 `GPT_MODEL=gpt-6-sol`。名称和输出模型字段来自中转站，无法独立证明底层模型身份。本版调用Responses API，不自动把密钥转发到其他服务商。

## 华为商城来源

- 通过华为商城电脑专区页面使用的公开内容接口读取商品卡片，保存商品名称、SKU、素材地址和读取时间。
- 商城快照缓存6小时，可在页面右上角连接状态中点击“刷新华为商城来源”。网络不可用时明确提示并使用已有快照或本地资料，不把失败伪装成实时检索。
- 本地10个型号仍可用。当前商城专区商品未覆盖旧款Windows型号，未匹配时只用其本地资料，不跨型号借图。
- 型号匹配区分 Pro / Pro S、Windows / 鸿蒙、芯片版本。商城事实目前提供商品身份、SKU和素材归属；参数仍以本地完整产品事实与脚注为依据。
- 商城促销、价格、库存和未注明条件的续航宣传不直接作为事实输出。商品卡片摘要不代替完整规格验证。
- 同一个素材组中的不同裁切比例只保留一个，另外排除相同地址和字节相同的本地图片。此去重不等于完整视觉相似度检测。
- 商品主图和商城素材在本机后端通过受限域名转发，浏览器不接触模型密钥；图片来源详情区分“华为商城”和“本地知识库”。
- 推荐先选 **HUAWEI MateBook Pro S** 体验商城补图，该型号本地6张、商城2张候选素材。实际输出图片由模型根据平台选择，不保证一次全部使用。

## 工作流程

明确型号与场景 → 本地事实 + 商城商品身份与素材 → GPT生成 → 原文引用检查 → GPT独立请求复核 → 必要时修正一次 → 复制/修改/Markdown、TXT、JSON导出。

生成和审核使用同一个配置模型、分别调用，不能视为不同模型的独立交叉验证。每次通常2—4次请求，异常JSON最多额外修复一次。使用费用按中转服务商计费。本版本不切换DeepSeek、不调用ima。

## 检查和交付

`npm test` 运行离线测试（不调用模型）。端到端结果见 `output/verification.json` 及 `output/examples/`。源码包不包含完整知识库、真实凭证及私有缓存。此版本仍是本地服务，尚未部署魔搭、GitHub或提交赛事。
