# 业务反馈与浏览器采集

2026-10-23，版本0.4。

## 从哪里操作

本地地址 http://127.0.0.1:8789/ 。新增顶部“业务反馈”，原有“内容研究”继续使用。

### 原帖文字

在内容研究中可以点击“浏览器读取”，使用独立匿名浏览器正常渲染公开页面。采集会检查来源域名、公网地址与robots规则，不自动登录或处理验证码。

抖音发布文案、作者、发布时间来自目标帖子的页面或同帖结构化数据，必须匹配视频ID。互动指标保存采集时间和依据；未提供的播放量保持未知，不以页面里的0占位值代替真实播放量。视频发布文案不等于视频语音、画面或完整内容转写。

如果网页受限，可点击“补充原文”，粘贴正文并填写作者、日期和取得方式。记录明确标为用户提供，保存独立快照。再次采集失败不会删除已补充的原文。

匿名页面若正常提供公开评论，浏览器只读取与该帖ID相符的提问文本和评论ID；不记录评论者身份，也不核验其是否购买。采集到的问题默认待人工核对，不算已确认的门店咨询。

### 顾虑记录

在业务反馈中选择来源：门店实际咨询、公开用户提问、官方FAQ、公开选题线索或模拟问题。填问题、场景和来源依据即可。不要填写姓名、电话等个人信息。

已通过官方页面读取导入12条FAQ线索，仍待人工核对；它们不等于真实客户访谈。展开“来源依据”可访问原始页面。实际核对后可点击“核对后确认”。模拟问题不会进入真实客户记录统计，也不会作为真实顾虑自动提供给生成模型。

### 人工改稿

生成结果下点击“记录采用与改稿”，或在业务反馈页选一份原稿。原稿由后端从原运行记录读取，最终稿与修改原因由你填写，并记录采用判断和人工确认。

文本未改变时记作评价，不冒充改稿对照。人工修改后的产品事实标记为待重新核验；即使勾选了人工确认，也不会被自动当成已核验训练集。

导出的反馈JSON包含来源标签、原稿、最终稿、原因、确认状态与原始产品证据快照。没有执行模型参数微调。后续创作只参考已确认的相关顾虑和采用原因，产品事实仍从原事实库取证。

## 运行与部署

本地使用既有Edge和Playwright组件；也可 npm install 后使用 playwright-core。Linux容器已补充Chromium安装步骤，Docker镜像构建需要联网下载依赖。云端构建本轮尚未实际执行。

环境变量：RESEARCH_BROWSER_ENABLED=0 可关闭浏览器回退；RESEARCH_BROWSER_EXECUTABLE 可指定浏览器；RESEARCH_PLAYWRIGHT_MODULE 可指定本地组件入口。数据库继续使用 RESEARCH_DATA_DIR 或 .cache/gpt/research。

原数据库升级为schema v2，只新增表并规范官方支持条目的类型；原始数据保留。顾虑与改稿保存流程在隔离库核对，正式库没有加入检查用的模拟记录。
