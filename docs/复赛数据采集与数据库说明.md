# 知序复赛：数据采集与研究数据库

日期：2026-10-23。以下区分已实现的软件功能与实际数据取得情况。

## 使用入口

本机预览：http://127.0.0.1:8789/ 。点击顶部“内容研究”。

本轮在 GPT 版上增加研究功能，DeepSeek 原版源码保留。修改前 GPT 源码备份位于工作区 output/复赛升级前-GPT-20261023。

## 已实现的流程

1. 四个平台：小红书、抖音、微博、微信公众号。每轮最多6组关键词、每组最多10条候选，共最多240条；原页读取预算最多40页，按平台轮流分配。
2. 搜索接入优先顺序：TAVILY_API_KEY → BRAVE_SEARCH_API_KEY → 已配置模型服务的 web_search 工具。当前中转服务实际返回了完成的联网调用。搜索不等同于原帖全文或互动数据；模型文字中的URL只有与搜索工具引用相符才接受。
3. 网络采集仅访问允许域名的公网 HTTPS 页面，检查 robots 规则，限制重定向、响应大小、请求时间和频率；不自动登录、不处理验证码。失败写入来源状态与原因。
4. SQLite 保存来源、搜索发现记录、任务过程、互动指标快照、产品文档、表达分析、分析输入快照和采用反馈。URL规范化后去重。
5. 可按平台、关键词查询；只有先选定一个平台，才允许按一项实际指标排序。缺失指标是 null，不能当作0；用户填报/导入的数据与原页提取数据分别标注。
6. 同平台选择1—12条有文字的案例，可用模型分析表达方式，保存引用与局限。同平台生成时附带最近两份研究，第三方资料不能进入产品事实。
7. 新增抖音图文/口播脚本与微博图文创作入口。抖音输出文字脚本和产品配图建议，不生成视频。
8. 修正完整型号前缀重叠时的误判（例如 Pro 是 Pro S 的前缀），按较长名称优先匹配；实际同时出现其他型号仍会拦截。
9. 可导入 JSON/CSV、导出当前来源 JSON。指标快照历史保留，可通过 GET /api/research/sources/:id/observations 读取。

## 实际数据覆盖

截至2026-10-23，库中132条来源：100条帖子链接（其中3条汽车主题排除），20条官方产品/规格页，12条官方支持页；本地10款产品已索引。12条抖音记录取得发布文案、作者、日期和至少一项互动计数，累计14次指标快照。它们不是视频全文转写，也不全是近期内容。小红书、公众号尚未取得有效原帖，微博目前主要是候选链接与搜索摘要。12条官方FAQ待人工核对，真实门店咨询和人工改稿样本均为0。

目前可用研究包含一份4条搜索摘要分析及一份8条浏览器采集案例分析。后一份按系统记录固定显示采集来源，历史误标来源的报告保留审计记录并停用，不参与后续生成。两份均不能证明传播效果。

业务反馈与浏览器操作见《业务反馈与浏览器采集说明.md》。没有执行模型微调。

## 数据库与持久化

本机数据库：gpt-version/.cache/gpt/research/research.sqlite。

SQLite WAL 模式可能同时产生 -wal 和 -shm 文件。运行时不要只复制主文件作为完整备份。使用 CLI backup 创建一致快照：

```powershell
node tools/research-cli.mjs backup ../output/研究库备份-新文件名.sqlite
```

RESEARCH_DATA_DIR 可指向持久化目录。在云端应为该目录配置持久化存储；默认容器内 .cache 不保证跨重建保留。随部署包附带 data/research/initial.sqlite，只在首次创建研究库时复制，后续优先使用现有数据库。

导出JSON适合交换来源与最新指标；完整数据库快照还包含历史指标、研究报告与任务记录。

## 导入与反馈

- 每行粘贴一个原帖URL可先入库，再尝试读取原页。
- 导入模板：研究数据导入模板.csv；JSON示意：研究数据导入示例.json。
- title、summary、excerpt、publishedAt 均可留空。阅读、播放、点赞等指标只能填实际观察到的非负整数，未知留空。
- 手工指标须填写 evidence，例如后台导出文件名及行号。用户导入/填报记录不会伪装成系统独立核验。
- 不同账号、观察时长、投流情况会影响比较；当前排序不是因果实验或全平台排名。

## 当前边界

现有结果足以支持产品来源核验和部分选题/表达研究，不能证明任何“流量密码”。没有进行模型微调。后续需要有依据的发布结果，才能验证创作策略。

云端部署包已同步到 output/魔搭部署-GPT，但本轮尚未替换线上空间。需要重新上传并构建后，线上才有研究功能。
